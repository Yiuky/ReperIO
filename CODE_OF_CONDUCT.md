# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todas as pessoas com respeito, aceite críticas construtivas, foque no que é melhor para
quem usa o ReperIO e não tolere assédio, ofensas ou exposição de dados pessoais de terceiros. Isso vale
para issues, pull requests e qualquer outro espaço do projeto.

Também não publique em issues, logs ou capturas de tela **nomes de servidores, IPs, caminhos internos ou
dados de organizações**: troque-os por exemplos genéricos.

Comportamentos inaceitáveis podem ser relatados de forma privada ao mantenedor, pelo recurso
[*Report a vulnerability*](https://github.com/Yiuky/ReperIO/security/advisories/new) (aba **Security**)
ou pelo perfil [@Yiuky](https://github.com/Yiuky).
